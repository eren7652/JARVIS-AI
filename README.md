# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/eren7652/JARVIS-AI.git
```

Go inside project

```bash
cd JARVIS-AI
```

Install backend

```bash
npm install
```

Install frontend

```bash
cd client
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file.

```env
MONGODB_URI=
JWT_SECRET=
GEMINI_API_KEY=
VITE_GOOGLE_CLIENT_ID=
```

For Vite frontend:

```env
VITE_API_URL=http://localhost:5000
```

---

# ▶️ Run Locally

Backend

```bash
npm start
```

Frontend

```bash
cd client
npm run dev
```
